## 快速開始

1. **開啟應用程式**：在瀏覽器中打開旅遊儀表板網址，或將其安裝為桌面/手機 App（PWA）。
2. **使用 Google 帳號登入**：點選右上角登入按鈕，選擇您的 Google 帳號。
3. **建立第一個旅程**：在首頁點擊「新增旅程」，輸入旅程名稱與日期。
4. **開始規劃**：進入「行程規劃」頁面，新增每日景點、航班與住宿。

## 登入與帳號

### 如何登入

- 本系統僅支援 **Google 帳號登入**。
- 點選右上角的登入按鈕，並依指示完成 Google 授權即可。

### 使用者角色

每個旅程都有自己獨立的權限設定，您在不同旅程中可能扮演不同角色：

| 角色 | 說明 |
|------|------|
| **Admin（管理員）** | 旅程的擁有者。擁有完整權限，可管理協作者、調整分享設定。 |
| **Member（成員）** | 被邀請進入旅程的協作者。可依管理員設定，對個別頁面擁有 **唯讀** 或 **可編輯** 權限。 |
| **Guest（訪客）** | 未被邀請的使用者。僅能在管理員開啟「公開權限」時瀏覽指定頁面。 |

### 分頁權限

管理員可以針對以下七個分頁分別設定每位成員的權限（**無權限／唯讀／可編輯**）：

- 行程規劃（planner）
- 航班（flights）
- 住宿（hotels）
- 票券（tickets）
- 待辦清單（checklist）
- 預算（budget）
- 資源（resources）

> 若您無法存取某些頁面，請聯絡該旅程的 Admin 調整您的權限。

## 主要功能介紹

### 🏠 首頁 (Home)

- 顯示您所有的旅程列表。
- 可切換目前正在編輯的旅程。
- 提供「新增旅程」與刪除既有旅程的功能。

### 🗺️ 行程規劃 (Planner)

旅程的核心頁面。您可以：

- **新增每日景點**：輸入名稱、地址、停留時間。
- **拖曳排序**：使用滑鼠（或手機觸控）將景點拖移至想要的順序或日期。
- **檢視地圖**：每日景點會顯示在 Google 地圖或 Leaflet 地圖上，並自動規劃路徑。
- **編輯時段**：點擊景點即可修改時間、備註或刪除。

### 🧳 行前準備 (Logistics)

集中管理出發前需要的所有資訊：

- **航班**：新增航班編號、起降時間、座位資訊。
- **住宿**：紀錄飯店名稱、入住/退房日期、地址與訂房編號。
- **票券清單**：管理門票、交通票券等。
- **花費預算**：記錄各項支出，掌握旅遊預算。

### 📚 資源 (Resources)

- 放置與旅程相關的外部連結、Google 文件、地圖網址等。
- 適合與隊友共享參考資料。

### ⚙️ 管理 (Admin)

僅限管理員使用：

- 調整使用者角色與權限。
- 設定旅程分享對象。
- 系統設定與 API Key 管理。

## 離線使用

本應用程式為 **PWA（漸進式網頁應用程式）**，支援離線使用。

### 離線時可以做什麼

✅ 瀏覽所有已下載過的旅程資料
✅ 新增、編輯景點、航班、住宿等資料（會暫存）
✅ 切換頁面、查看地圖快取

### 離線時的限制

❌ 無法載入新的地圖區域
❌ 無法即時與其他成員同步

> 🔄 當您重新連線後，系統會自動將離線時的變更同步到雲端。

### 安裝為 App

- **電腦版（Chrome / Edge）**：點選網址列右側的「安裝」圖示。
- **iPhone / iPad（Safari）**：點分享按鈕 → 加入主畫面。
- **Android（Chrome）**：點選右上角選單 → 安裝應用程式。

## 常見問題 (FAQ)

### Q1：我的資料會儲存在哪裡？
A：所有資料儲存於 Google Firebase 雲端，並會在您本機瀏覽器中保留快取，方便離線使用。

### Q2：可以多人共同編輯同一個旅程嗎？
A：可以。管理員可在「管理」頁面設定旅程的分享對象，被授權的使用者可以即時看到彼此的變更。

### Q3：手機可以用嗎？
A：可以！本應用程式為響應式設計，支援手機與平板，並可安裝為 PWA App 使用。

### Q4：資料不見了怎麼辦？
A：請先確認您是否登入了正確的 Google 帳號。若仍有問題，請聯絡管理員協助確認雲端資料狀態。
